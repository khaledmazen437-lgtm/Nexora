# Nexora — Team Registration & Evaluation Form

> استمارة تقييم وتوزيع التيمات لمجتمع Nexora التقني — تسجيل البيانات وتوزيع الأعضاء على الفرق.

An Arabic (RTL) single-page registration and evaluation form for the Nexora tech community: applicants submit their details and get assigned to teams.

## Features

- Styled RTL form with animated background effects
- Client-side validation and a success confirmation state
- Single self-contained `index.html` — no build step

## Tech Stack

- Vanilla HTML/CSS/JS

## Running

Open `index.html` in a browser.
